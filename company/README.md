# Company OS — équipe interne générique

Ce dossier définit les onze rôles internes utilisés par chaque projet connecté. Les rôles sont des modèles partagés ; les conversations, travaux, décisions, mémoires et livrables sont isolés dans l’espace du projet.

- Le propriétaire parle au CEO du projet ouvert.
- Le CEO délègue aux dix spécialistes selon leurs manifestes.
- Les pipelines applicatifs restent du logiciel, jamais des agents de société.
- Aucune action externe, dépense, publicité, publication, paiement ou production n’est autorisée sans approbation explicite enregistrée.
- Aucun secret, contenu client brut ou donnée personnelle ne doit entrer dans la mémoire ou les journaux.

Le registre des rôles se trouve dans `roster.yaml`. Les règles propres à un produit restent exclusivement dans le dépôt connecté et son `AGENTS.md`.
